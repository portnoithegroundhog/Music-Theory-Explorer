Music Theory Explorer

One file, no server, no external dependencies, nothing sent anywhere except to the local MIDI bridge on your own machine (and only if you turn MIDI out on). Explore a scale by ear, play it on the keyboard, find new scales, record what you play, and send it on to other programs on your own machine. It is a dream synth for learning music theory, not a replacement for any other program.

About this synthesizer

You can download this page, save it, and use it offline with full functionality. The only extra file you need, and only if you want MIDI out, is midi-bridge.py in the same folder, explained in the box in section 5. 4. Synth voice

Voicing sets the timbre: waveform, harmonics, filter, vibrato and decay. The Waveform dropdown below is kept only as a fallback for older saved recordings.

Effects (colour and flavour, not VST replacements)

One shared effects bus: every voice feeds the same chain, then master volume, so live sound, playback and WAV all match. Order: voice → distortion / harmonics → high-pass / low-pass → chorus → delay → reverb → master. Each effect has an on/off switch, a slider and a number box with the same value. Ranges are wide on purpose: extreme settings are allowed to sound weird. Click is dry, it does not go through effects, and it is not recorded or exported.

MIDI bridge: get this file and run it

Download midi-bridge.py and put it in the same folder as this page. This page assumes the bridge file is in the same folder, for simplicity.

How to run it (Linux / Unix / BSD):

  1. Install the bridge dependencies. Either with pip:
    python3 -m pip install mido python-rtmidi websockets
    or, on Debian / Ubuntu / Peppermint, with apt:
    sudo apt install python3-rtmidi python3-websockets (plus mido from your distribution if it is available).
  2. In a terminal, in the folder with this page and the bridge file, run:
    python3 midi-bridge.py
    Leave that terminal running while you play. The bridge opens a virtual MIDI port called MuseSynth and listens on your own machine only, at ws://127.0.0.1:8765.
  3. Back on this page, in section 5, click Connect to MIDI bridge, then tick MIDI out on. Local sound stays on unless you untick it.
  4. Route MuseSynth to your synth or program. See the About page for full, step-by-step guides for QjackCtl, Rosegarden, Audacity and VCV Rack.

Nothing is sent to the internet by this page or by the bridge. MIDI out is off by default. If you only want the built-in sound, or the WAV export, you do not need the bridge at all.

6. Keyboard

Per-row: each row starts at its own octave and cycles the scale across its 10 keys. A 10-note scale fills a row exactly; a 3-note scale repeats. With 11 or 12 notes, per-row rows can only show the first 10 degrees, so use Continuous to reach every degree (keys run in order z-row, a-row, q-row, 1-row).

Play with the mouse / touch, or with QWERTY keys. Rows, lowest to highest: z to /, then a to ;, then q to p, then 1 to 0. QWERTY playing is disabled while you are typing in a text box, so typing a step pattern does not sound notes. Pressing a key starts its note; releasing it stops it.

7. Chords of the current mode

Triads are built on each degree from degrees 0, 2 and 4 above it (modulo the note count, wrapping up an octave when needed). Dyads are adjacent degrees. Hold a button down to hear the chord; release to stop it.

8. Scale finder

Find scales by EDO, note count, and minimum interval — without repeating the crash of the lost synth, which tried to list millions of patterns at once. The finder first shows an estimated count, then runs in a Web Worker (so the page stays responsive) with progress and a Cancel button. The finder list shows step patterns only — no frequencies or note names — until you click a scale and then a mode. Tuning runs lazily at that point, in section 1, for the one mode you chose. Evenness defaults below are starting proposals to tune by ear, not fixed musical claims: if a favourite scale gets filtered out, loosen the filter.

Must-include filters are requirements, not upper bounds, and they are applied before top-N ranking: a streamed top-1000 run with Must include step 5 returns the top 1000 among patterns containing a 5, by CV ascending. A sub-pattern is checked cyclically, so a pattern ending in 5 and starting in 2 contains 5-2. The run status reports how many patterns pass Must-include, so you can tell whether a scale with that step or sub-pattern exists at all.

Modes of the selected finder scale

Click a finder result above, then click a mode below to load it into the keyboard, statistics table, and chord buttons above, with the current bell note and octave. Modes are the distinct rotations of the step pattern, deduplicated.

Full filtered list as text

This is separate from the on-screen top-N list above. It runs the worker with the current filters (including Must-include, if set), regardless of the 200,000 full-list threshold and regardless of Top N, and produces the entire filtered list as text — one pattern per line, step pattern plus evenness stats only, no tuning or frequencies, so the maths separation holds. The preview shows only the first 200 lines, so the page does not try to render hundreds of thousands of lines; use Download or Copy for the whole list.

9. Recorder and exports

Record what you play, then play it back or download it. Recording captures an event list first — every note and chord note you play, with its own frequency, cents from tonic, nearest MIDI note and bend, start time and duration — and every export below is rendered from that same list, so the exports always agree with each other. Timing is real time, gridless: no quantization, except that the MusicXML export has to quantize to its divisions grid (see its label). Changing the scale, bell note or octave after recording does not change a recording, because each event carries its own frequency. Playback always uses local sound, with the voicing, effects, ADSR and master volume as currently set. The event list below is not displayed while recording, to avoid display lag — it appears when you press Stop recording.
