MuseSynth MIDI bridge test

This page makes no sound by itself. It sends MIDI through the bridge script to your synth (VCV Rack, QSynth, Ardour, etc.). If you hear nothing, the break is in the MIDI chain, not in a synth engine, which is exactly what this test is for.

Not connected.

Order matters: start JACK, start the bridge (python3 midi-bridge.py), connect MuseSynth to your synth in QjackCtl, then press Connect here. See README-midi-bridge.md.
